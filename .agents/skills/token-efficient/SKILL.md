# Réponses

- Aller droit au résultat ; pas de reformulation de la demande ni de récapitulatif final.
- Réponse simple : moins de 300 mots. Explication longue seulement si demandée.
- Au plus trois options, avec une recommandation.

# Lecture et édition

- Lire uniquement les fichiers nécessaires ; pas d'analyse de tout le dépôt sans raison.
- Modifier les lignes concernées (patch) plutôt que réécrire un fichier.
- Ne pas réafficher le code inchangé ; donner d'abord le diff ou le bloc modifié.
- Ne pas ajouter de commentaires superflus.
- Demander avant une refonte importante.
